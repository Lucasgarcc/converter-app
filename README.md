# 💱 Converter App — Conversor de Moedas

Aplicação mobile/web de conversão de moedas desenvolvida como **teste técnico**, com suporte para conversão entre até duas moedas simultaneamente, exibição de histórico de conversões e atualização em tempo real via integração com API externa.

---

## 🚀 Tecnologias Utilizadas

- **[Angular](https://angular.io/)**: Framework principal para estruturação do projeto, componentes e serviços.
- **[Ionic Framework](https://ionicframework.com/)**: UI Component Library para interface mobile/responsive.
- **TypeScript**: Superset JS para tipagem estática e prevenção de erros.
- **RxJS / HttpClient**: Gerenciamento de chamadas assíncronas à API de cotação.
- **HTML5 & SCSS**: Estilização e layout responsivo.

---

## 🎯 Objetivo do Projeto

O objetivo deste projeto foi atender aos requisitos do teste técnico proposto, demonstrando boas práticas de desenvolvimento frontend, arquitetura limpa e consumo de dados assíncronos.

### Key Features
- 🔄 **Conversão Simultânea**: Suporte para conversão rápida entre até duas moedas.
- 📊 **Histórico de Conversão**: Acesso ao registro de conversões realizadas através de um botão dedicado.
- 🌐 **Integração com API**: Cotação em tempo real consumindo API REST externa de dados cambiais.
- 📱 **Interface Responsiva**: Design adaptado para telas mobile e desktop com componentes Ionic.
